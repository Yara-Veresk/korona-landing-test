# Тестовый пакет GitHub Pages — «Корона из пепла»

Пакет подготовлен 11.10.2026 как резерв Yandex Cloud.

## Что публиковать

Загрузите **содержимое этой папки в корень репозитория**, сохранив каталоги `assets`, `css`, `js`. Файл `.nojekyll` обязателен. Не используйте Git LFS.

В Settings → Pages выберите `Deploy from a branch`, ветку `main`, папку `/ (root)`.

## Что проверять

1. Сначала откройте `https://ИМЯ.github.io/РЕПО/rf-test.html`.
2. Попросите 2–3 пользователей из РФ на разных сетях (домашний интернет и мобильные операторы) прислать скрин итогов.
3. Затем откройте `index.html` и визуально проверьте весь лендинг.
4. Проверяйте без VPN. Желательно: один домашний провайдер, МТС/Мегафон/Билайн/Т2 в разных сочетаниях.

Все изображения обычной версии хранятся в репозитории и запрашиваются с того же домена GitHub Pages (`*.github.io`), а не с `raw.githubusercontent.com`.

`index-single-file.html` — тяжёлый аварийный вариант: CSS, JS и все изображения встроены внутрь одного HTML. Использовать только если обычная страница открывается, а отдельные изображения не грузятся.

## Ограничения тестовой версии

- ссылки Author.Today пока ведут на заглушку `https://author.today/`;
- Метрика и финальные UTM/yclid ещё не подключены;
- установлен `noindex,nofollow`;
- VK-видео запрашивается только после ручного клика и остаётся внешним ресурсом.
